# Samsung Health Fitness & Activity Analysis Dashboard

## Overview
An interactive Power BI dashboard designed to track and analyze individual daily, weekly, and monthly fitness progress using personal activity logs exported from the **Samsung Health** app. The project focuses on uncovering behavioral patterns, workout consistency, and cycle-on-cycle performance trends.

## Objectives
* Clean, structure, and standardize raw individual activity logs from the Samsung Health app.
* Perform Exploratory Data Analysis (EDA) across key fitness metrics (steps, calories burned, active minutes, and workout frequency).
* Build an intuitive, interactive dashboard with dynamic KPI cards and date slicers for multi-timeframe progress tracking.

## Tools & Technologies
* **Data Visualization:** Power BI (DAX, Interactive Slicers, KPI Cards)
* **Data Cleaning & Transformation:** Excel / Power Query
* **Analytics:** Exploratory Data Analysis (EDA), KPI Tracking, Cycle-on-Cycle Analysis

## Dataset
* **Source:** Personal activity dataset compiled from the Samsung Health app for an individual user.
* **Key Metrics Tracked:**
  * Daily Step Count
  * Calories Burned
  * Active Time (Minutes)
  * Workout Sessions & Consistency

## Key Dashboard Features
* **Dynamic KPI Cards:** Real-time summary of total steps, average daily calories burned, active minutes, and goal completion rate.
* **Multi-Timeframe Filtering:** Interactive slicers to toggle seamlessly across daily, weekly, and monthly views.
* **Cycle-on-Cycle Trend Analysis:** Visual breakdowns comparing week-over-week and month-over-month activity levels to pinpoint peak performance days and consistency gaps.
